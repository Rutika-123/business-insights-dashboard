# Business Insights Dashboard — React + Vite + Bootstrap

Frontend-only Business Intelligence dashboard prototype based on the supplied visual reference.

## Features

- Fixed Business Insights sidebar
- Sales Analysis, Customer Analysis and Product Analysis sections
- Active sidebar navigation without React Router
- KPI cards
- Sales trend, regional donut, category, product, customer and ship-mode visualizations
- Recent Orders table
- Responsive desktop/tablet/mobile layout
- Floating AI Business Analyst button
- Animated right-side chatbot panel
- Mock chat responses only — no AI/LLM API
- Bootstrap + custom CSS, no Tailwind

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Later integrations

The mock values can later be replaced with:
1. API/database data
2. Power BI Embedded or another BI integration
3. A real AI backend/API for the chatbot
